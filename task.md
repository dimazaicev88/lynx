# **Описание языка**

Язык называется Lynx. Язык строго типизированный.

### Типы данных

- Number
- Any
- Unknown
- String
- Array
- Null

### Объявление переменных

Константы:

const a=10;
или
const a:Number=10;

Изменяемые переменные:
var b=10;

var b:Number=10;
